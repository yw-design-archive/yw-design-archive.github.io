# 王蕴 · 设计作品集

完整静态网站，保留原有动效、音效和内容编辑窗口。

## GitHub Pages 发布

1. 将本目录全部文件上传到 GitHub 仓库的 main 分支根目录。
2. 仓库 Settings → Pages → Build and deployment 选择 Deploy from a branch。
3. 选择 main 和 / (root)，保存。
4. 等待 GitHub Pages 部署完成，使用 Settings → Pages 显示的网址。

账号主页仓库须命名为“账号名.github.io”；普通项目仓库的网址是“https://账号名.github.io/仓库名/”。

## 内容编辑窗口

在网站地址后加 /edit.html 即可进入编辑窗口（项目网址则在仓库路径后加 edit.html）。
编辑内容可保存为本机草稿、预览，并下载 content.json。
要让修改公开生效，请把下载的 content.json 替换到仓库根目录并提交，Pages 会再次部署。
这里没有服务端密码或数据库；访问者的本机草稿不会改变线上网站。

## 后续修改

HTML/CSS/JS 和 assets 均在仓库中，可继续修改。
原 Sites 网址继续保留，可通过原 Codex 聊天继续编辑；Sites 和 GitHub Pages 是两个发布目标，修改后需要分别同步。
